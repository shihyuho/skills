# sdkman

Manage development tools and execution environments with [SDKMAN](https://sdkman.io/) according to the task's needs.

Uses the native CLI for version queries, installation, removal, defaults, and project environments, with no Python dependency. One-command switches stay local to that shell; persistent changes follow the user's explicit request.

## Install

```bash
npx skills add shihyuho/skills --skill sdkman -g
```
