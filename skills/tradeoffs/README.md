# tradeoffs

Recommend a discussed option by weighing its added value against cost, risk, and complexity, with evidence that would change the recommendation.

This skill must be invoked explicitly.

The comparison follows the decision's needs, including only decisive research and assumptions. It finishes in chat; saving happens only when requested, preserving existing files with a numbered suffix.

## Installation

```bash
npx skills add shihyuho/skills --skill tradeoffs -g
```
