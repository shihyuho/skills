# tradeoffs

Recommend a discussed option by weighing its added value against cost, risk, and complexity, with supporting evidence and conditions that would change the recommendation.

This skill must be invoked explicitly.

The comparison checks only unknowns that could change the recommendation, grounding repository claims in actual implementation and external claims in primary sources while making uncertainty explicit. It finishes in chat; saving happens only when requested, preserving existing files with a numbered suffix.

## Installation

```bash
npx skills add shihyuho/skills --skill tradeoffs -g
```
