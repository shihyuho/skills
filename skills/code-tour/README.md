# code-tour

帶你沿著一個功能的實際程式路徑閱讀，串起入口、參與角色、分支條件與執行結果，並以適合的圖和原碼連結協助理解。

適合接手不熟悉的功能、理解跨檔案的呼叫關係，或看懂一個宣告究竟在哪裡影響行為。這個 skill 需要明確調用。

## 開始使用

先讓 agent 能讀取目標 repo，再給它功能、符號或入口；也可以沿用目前對話正在討論的程式。

```text
$code-tour 帶我看訂單送出後，從 HTTP 入口到資料寫入的流程。
```

```text
$code-tour 這個 JobMarker 沒有方法，為什麼實作它會改變載入方式？
```

你會得到一個具體情境的解說、需要的圖，以及按閱讀順序排列的原碼位置，每個位置都說明值得看什麼。後續可以直接接著問「再展開這個分支」，不用重新走完整個 repo。

Class diagram 適合看型別與角色；sequence diagram 適合看呼叫次序、分支與效果。只有兩者各自補足不同關係時才合用；局部問題也可能只需要短文或程式片段。

## 輸出與限制

預設在對話中導讀。若要留下文件，可指定「把這次導讀存成 `docs/order-tour.md`」；文件會附上查閱的版本資訊。

導讀以實際程式為依據，不會修改實作。動態設定、外部套件或執行環境若無法查證，會在受影響的步驟說明；依原碼推演的路徑也會與實際執行觀察分開。圖與來源連結會隨程式改動而過時，閱讀保存的文件時應核對版本。

不需要額外安裝繪圖工具；支援 Mermaid 的介面可直接顯示圖，否則使用文字表示。研究依據與實驗限制見[程式理解研究筆記](../../docs/research/code-comprehension-and-diagrams.md)。

## 安裝

```bash
npx skills add shihyuho/skills --skill code-tour -g
```
